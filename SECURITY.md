# Security policy

## Supported versions

The latest GitHub Release receives security fixes.

## Reporting

Do not open a public issue for a vulnerability. Use GitHub's private
**Report a vulnerability** flow on the repository Security tab and include:

- affected version and platform;
- exact command or crafted input;
- observed filesystem or archive impact;
- minimal reproduction;
- suggested containment, if known.

Avoid including real credentials or private Codex data. Reports concerning
unsafe install destinations, path traversal, archive extraction, lock handling,
or backup loss are treated as high priority.
